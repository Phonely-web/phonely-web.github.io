# Phonely

¿Qué móvil comprar? Responde 6 preguntas y Phonely te recomienda los 3 móviles que mejor encajan contigo, nuevos o reacondicionados.

Disponible en español, English, català, français, italiano y português.

Web estática: abre `index.html` con un servidor local (`python3 -m http.server`) o publícala con GitHub Pages.
